05 / Founder review

A foundation to decide on.

Review this light slice before choosing an adoption page. Nothing here changes the shipped site or app.

  1. Semantic roles: accept or amend the proposed light mappings, including green actions and dark text on pink.
  2. Card recipe: A / Comfortable is the suggested web starting point; B / Compact stays available for lists.
  3. First adoption page: choose one website page and confirm scope before any appearance changes.

Dark semantics, Material elevation 0/2, app integration and release timing are still unresolved. No paid design tool is required for this catalog. For a future pilot, follow the reference evidence and page-variant review protocol.
