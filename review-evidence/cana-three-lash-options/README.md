# Cana: exactly three white lash alternatives

Review-only alternatives based on `0cc81a1eafa24adce523866fa3082ccad851116b`. No option is selected.

- **A — Soft curves:** three short rounded downward strokes per eye.
- **B — Graduated fan:** four curved tapered strokes, gently longer and sweeping toward the outer side.
- **C — Fine wisps:** five thinner tapered strokes, distributed across the lid with lighter density than the prior six-stroke design.

Start with `Cana-ABC-comparison.png` or the self-contained `index.html`. Each column shows full Cana at the same normal display scale, followed by an identical face crop. Individual labeled cards are `A-review-card.png`, `B-review-card.png` and `C-review-card.png`.

Each `A/`, `B/`, `C/` folder contains `Cana-normal.png`, `Cana-face-closeup.png`, `Ranca-Cana-normal.png`, native `Cana.svg` / `RancaCana.svg`, named `editable-layers.json`, and standalone HTML previews. SVG/HTML files embed original body image bytes. The JSON layer trees reference `assets/` relative to this bundle root. Every lash remains a separate named vector path; body textures remain unchanged raster images.

All relaxed eyelid paths and eye directions are preserved exactly. Mouth, body, hands, size, colors, Ranca and Cana’s 90% relative height are unchanged. Build-time comparison proves the entire non-lash layer tree is identical to the baseline. No eyebrows or eye rotations are added.

Rendered normal-size faces and enlarged crops were visually inspected. `check.json` records identical scale/crops, lid geometry, white lashes, 3/4/5 counts, attachment and spacing, restrained lengths, taper and pixel-identical SVG/HTML exports. This is static review only; no animation, rollout, import, MagicPath retry or permanent brand choice.
