# rancana-web

Static marketing site for [Rancana](https://rancana.id) (landing + privacy / terms / delete-account).

Plain HTML/CSS/JS. No framework.

```bash
python3 -m http.server 8899
# open http://localhost:8899/
```

Language: ID/EN via `lang.js` (`?lang=`, `localStorage`, or Indonesian timezone/locale).
